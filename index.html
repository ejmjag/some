01 · НЕГІЗГІ ТҮСІНІК

Indefinite Pronouns деген не?

Indefinite Pronouns — белгісіздік есімдіктері. Олар адамның, заттың немесе орынның нақты кім/не/қай жерде екенін атамай, жалпы немесе белгісіз түрде көрсетеді.

Сөздің бірінші бөлігі мағынаны анықтайды:
some- → біреу / бір нәрсе / бір жерде; көбіне affirmative
any- → біреу/бір нәрсе бар ма; negative/question; affirmative-де «кез келген»
every- → барлығы / барлық жерде

Соңғы бөлігі нені айтып тұрғанын көрсетеді:
-one / -body → адам
-thing → зат / нәрсе
-where → орын
Мысалы: some + one = someone → біреу; any + thing = anything → бір нәрсе / ештеңе (negative контексте); every + where = everywhere → барлық жерде.
АдамЗат / нәрсеОрын
SOMEsomeone / somebodysomethingsomewhere
ANYanyone / anybodyanythinganywhere
EVERYeveryone / everybodyeverythingeverywhere
Someone is waiting for you.
Сені біреу күтіп тұр.
I need something to drink.
Маған ішетін бір нәрсе керек.
02 · SOME-COMPOUNDS

Someone / Somebody / Something / Somewhere

Some- формалары көбіне affirmative сөйлемдерде қолданылады.

someone / somebody → біреу
something → бір нәрсе
somewhere → бір жерде / бір жерге
Someone called me yesterday.
Кеше маған біреу қоңырау шалды.
There is something in the bag.
Сөмкеде бір нәрсе бар.

Some- сұрақта қашан болады?

Жалпы ереже бойынша сұраулы сөйлемде any қолданылады. Бірақ some да сұрақта келе алады. Бұл әсіресе бір нәрсені ұсынғанда (offer) немесе өтінгенде (request) маңызды.

Негізгі айырмашылық:
Жай ақпарат сұрау → көбіне any.
Ұсыныс / өтініш, оң жауап күтіледі → көбіне some.

1. WOULD YOU LIKE + SOME + NOUN?

Would you like...? — біреуге бір нәрсе ұсынудың сыпайы формасы. Егер ұсынатын нәрсе noun болса, some + noun қолдануға болады.

WOULD YOU LIKE + SOME + NOUN?
Would you like some coffee?
Кофе ішесіз бе? / Кофе қалайсыз ба?
Would you like some water?
Су қалайсыз ба?
Would you like some cake?
Торттан аласыз ба?
Неге some? Бұл жерде біз жай ғана «кофе бар ма?» деп ақпарат сұрап тұрған жоқпыз. Біз адамға кофе ұсынып тұрмыз. Сондықтан сұрақ болса да some табиғи қолданылады.

2. WOULD YOU LIKE + SOMETHING?

Нақты затты атамай, «бір нәрсе» деп ұсынсақ, something қолданамыз.

WOULD YOU LIKE + SOMETHING + ...?
Would you like something to drink?
Бір нәрсе ішкіңіз келе ме?
Would you like something to eat?
Бір нәрсе жегіңіз келе ме?
Would you like something sweet?
Тәтті бір нәрсе қалайсыз ба?
Құрылымға қара: something to drink, something to eat, something sweet. Something-нан кейін оның қандай нәрсе екенін нақтылайтын сөз/құрылым келе алады.

3. WOULD YOU LIKE + TO + VERB?

Егер бір нәрсені емес, әрекетті ұсынсақ, Would you like to + V1? қолданылады.

WOULD YOU LIKE + TO + VERB?
Would you like to sit down?
Отырғыңыз келе ме?
Would you like to come with us?
Бізбен бірге барғыңыз келе ме?
Would you like to have some tea?
Шай ішкіңіз келе ме?
Есте сақта:
Would you like some coffee? → noun
Would you like something to drink? → indefinite pronoun
Would you like to drink something? → to + verb

4. REQUEST — БІР НӘРСЕНІ ӨТІНУ

Бір нәрсені сұрап, оның берілуін немесе орындалуын күткенде де some жиі қолданылады.

Can I have some water, please?
Маған су бересіз бе?
Could I have some sugar?
Маған қант бересіз бе?
Can someone help me?
Маған біреу көмектесе ала ма?
Логика: сөйлем сұрақ формасында болғанымен, сөйлеуші тек ақпарат іздеп тұрған жоқ — ол өтініш жасап тұр және көмектесетін/беретін адам болады деп күтеді.

5. SOME vs ANY — сұрақта

ЖағдайҚолданысМысал
Жай сұрақ, жауап белгісізanyDo you have any coffee?
ҰсынысsomeWould you like some coffee?
ӨтінішsomeCan I have some coffee?
Белгісіз адамның бар-жоғын сұрауanyoneIs anyone there?
Exam trap:
Do you have any questions? ✅ — жай сұрақ.
Would you like some tea? ✅ — offer.
Can I have some tea? ✅ — request.
03 · ANY-COMPOUNDS

Anyone / Anybody / Anything / Anywhere

Any- compounds көбіне сұраулы және болымсыз сөйлемдерде қолданылады.

anyone / anybody → адам
anything → зат / нәрсе
anywhere → орын

1. ANY- сұраулы сөйлемде

Біреудің, бір нәрсенің немесе бір жердің бар-жоғын білмесек, сұрақта any-form қолданамыз.

QUESTION + ANY-FORM
Did anyone call?
Is there anything in the box?
Did you go anywhere yesterday?
Мұнда сөйлеуші оң жауапты алдын ала күтпейді. Ол жай ғана ақпарат сұрап тұр.

2. ANY- болымсыз сөйлемде

Сөйлемде not / n't арқылы negative verb болса, әдетте any-form қолданылады.

NEGATIVE VERB + ANY-FORM
I don't know anyone here.
I didn't buy anything.
We couldn't go anywhere.
❌ I don't know someone here.
✅ I don't know anyone here.

❌ I didn't buy nothing. (standard English)
✅ I didn't buy anything.
Did anyone call?
Біреу қоңырау шалды ма?
I didn't see anybody.
Мен ешкімді көрмедім.
I don't know anything about it.
Мен ол туралы ештеңе білмеймін.

3. ANY- affirmative сөйлемде = «кез келген»

Any-form тек question/negative үшін емес. Affirmative сөйлемде ол көбіне кез келген адам / кез келген нәрсе / кез келген жер деген мағына береді.

anyone → кез келген адам
anything → кез келген нәрсе
anywhere → кез келген жерде / жерге
Anyone can learn English.
Кез келген адам ағылшын тілін үйрене алады.
You can sit anywhere.
Кез келген жерге отыра аласың.
Exam trap: negative verb бар болса, әдетте any-form қолданылады:
✅ I don't know anyone here.
❌ I don't know someone here.
04 · EVERY-COMPOUNDS

Everyone / Everybody / Everything / Everywhere

Every- compounds белгілі бір топтың немесе жағдайдың барлығын толық қамтиды.

everyone / everybody → барлық адам / бәрі
everything → барлық нәрсе / бәрі
everywhere → барлық жерде

1. Everyone / Everybody — барлық адам

Everyone және everybody мағынасы бірдей. Олар адамдар тобындағы әр адамды қамтиды.

Everyone is ready.
Барлығы дайын.
Everyone ≠ every one.
everyone → барлық адам.
every one (of...) → топтағы әрқайсысы: Every one of these answers is important.

2. Everything — барлық нәрсе

Everything заттар, жағдайлар немесе ақпараттың барлығын білдіреді.

Everything is ready.
Барлығы дайын.

3. Everywhere — барлық жерде

Everywhere орынға қатысты. Оның алдында әдетте in / at / to қажет емес.

We looked everywhere.
Біз барлық жерден іздедік.
❌ in everywhere
✅ everywhere
Everyone is ready.
Барлығы дайын.
Everything looks fine.
Барлығы жақсы көрінеді.
We looked everywhere.
Біз барлық жерден іздедік.
05 · VERB AGREEMENT

Indefinite Pronouns + Singular Verb

-one, -body және -thing арқылы жасалған indefinite pronouns мағынасы бірнеше адамға қатысты көрінсе де, грамматикалық тұрғыдан singular болып есептеледі.

someone / somebody + singular verb
anyone / anybody + singular verb
everyone / everybody + singular verb
something / anything / everything + singular verb

Present Simple-де бұл әсіресе is / has және етістікке -s/-es жалғауынан көрінеді.

Everyone is ready. ✅
Someone has called. ✅
Everything looks good. ✅
❌ Everyone are ready.
✅ Everyone is ready.
Бірақ кейінгі pronoun басқа болуы мүмкін: қазіргі ағылшын тілінде жынысы белгісіз адамға қайта сілтеме жасағанда singular they / them / their қалыпты қолданылады:

Someone has left their bag.
Someone = грамматикалық singular → has.
Жынысы белгісіз → кейін their қолдануға болады.
❌ Everyone are ready.
❌ Someone have called.
❌ Everything look good.

✅ Everyone is ready.
✅ Someone has called.
✅ Everything looks good.
06 · ELSE & ADJECTIVES

Something else · Someone new

1. ELSE — «тағы / басқа»

Else «тағы», «басқа» деген мағына береді және indefinite pronoun-нан кейін орналасады.

indefinite pronoun + ELSE
someone else → басқа біреу
something else → басқа/тағы бір нәрсе
anyone else → тағы біреу / басқа біреу
anything else → тағы бір нәрсе
somewhere else → басқа жерде
Do you want anything else?
Тағы бір нәрсе қалайсың ба?
Someone else answered the question.
Сұраққа басқа біреу жауап берді.

2. Adjective қай жерде тұрады?

Кәдімгі noun-мен adjective көбіне noun-ның алдында тұрады: an interesting book. Бірақ indefinite pronoun-мен adjective кейін тұрады.

INDEFINITE PRONOUN + ADJECTIVE
something interesting
someone new
anything useful
nothing important
Салыстыр:
an interesting book → adjective + noun
something interesting → indefinite pronoun + adjective
❌ interesting something
✅ something interesting
07 · QUICK COMPARE

Some vs Any vs Every — қалай ажыратамыз?

1. Affirmative және «біреу/бір нәрсе» → көбіне some-.
2. Question/negative → көбіне any-.
3. Offer/request және оң жауап күтілсе → сұрақта да some-.
4. Affirmative-де «кез келген» → any-.
5. «Барлығы» → every-.
ФормаНегізгі мағына/жағдайМысал
someone / somethingбелгісіз біреу/бір нәрсе; көбіне affirmativeSomeone is outside.
anyone / anythingquestion / negative; affirmative-де «кез келген»Did anyone call?
everyone / everythingбарлығыEveryone is here.
Negative pronouns-пен байланысы:
I saw nobody. = I didn't see anybody.
I know nothing. = I don't know anything.
